# Starry Product Lab Pet Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add three four-state roaming desktop residents and refine the v5 interface toward the supplied Moonpie star-lab references.

**Architecture:** Keep pet data and transition logic pure in `pets.ts`, isolate browser timing and movement in `usePetRoaming.ts`, and render residents through `DesktopPets.tsx`. `App.tsx` only owns the persisted Pet Mode setting and composition; existing portfolio and Terminal behavior remains intact.

**Tech Stack:** React, TypeScript, Framer Motion, requestAnimationFrame, Vitest, Testing Library, ImageGen assets.

## Global Constraints

- Modify only `work/star-lab-os-v6-pets`; preserve v5.
- Primary brand remains `✦ Starry Product Lab`.
- Pets have only `idle`, `walk`, `sit`, and `react` states.
- Desktop roaming stays in the bottom 40% and avoids primary controls.
- Mobile uses a stationary resident tray.
- Pet Mode defaults on and persists locally.
